Oxid

Ephemeral environments that breathe.

Ferrous performance, invisible footprint.

A self-hosted control plane that deploys a preview environment for every branch you push — and actually scales it to zero when nobody's looking.

★ Star on GitHub Read the roadmap

// why

Staging environments shouldn't cost like production ones.

The problem

A preview environment per feature branch usually means one of two things: paying a cloud platform for staging instances that sleep 90% of the time, or drowning your local server (or NAS) in Docker containers nobody remembers to stop.

The Oxid way

Oxid detects a push, injects secrets, deploys the container, connects it to a proxy — and if nobody visits it in 30 minutes, it pauses in memory. The next visit wakes it in milliseconds. Vercel-style preview URLs, at the resource cost of a calculator.

// what it offers

Opinionated, so you don't have to configure it.

Zero friction

No YAML novels. If there's a Dockerfile, Oxid knows what to do. Drop an oxid.toml when you want more control.

Real scale-to-zero

Idle branches get paused in memory, not just billed differently. First request wakes the container and serves you like nothing happened.

Resource multiplexing

One shared Postgres, one shared Redis — dozens of branches, one logical database each. No cluster sprawl for ephemeral data.

Fully local, fully audited

No external database required. Every deploy, log line, and injected variable is recorded in an embedded, transactional SQLite.

One control plane, many surfaces

CLI, TUI, web dashboard and a lightweight desktop app all talk to the same daemon — pick whichever fits the moment.

Written in Rust

A single static binary, minimal memory footprint, unsafe forbidden workspace-wide. Built to sit quietly on hardware you already own.

// the golden path

You never feel the machinery.

  1. 01

    Install

    One binary. Point a wildcard domain at it (*.local.dev), mount the Docker socket.

  2. 02

    Push a branch

    git push origin feature-carrito — that's the entire interface.

  3. 03

    The magic

    Oxid clones, builds, injects secrets, and deploys. The proxy routes feature-carrito.local.dev automatically.

  4. 04

    Breathe

    No traffic for a while? Oxid pauses it and gives the RAM back. A tester opens the URL — it wakes in milliseconds.

oxid up feature-login
